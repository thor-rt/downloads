# THOR downloads

THOR is a radiative transfer code. This repository hosts versioned desktop builds.
Choose a build for your platform on the [Releases page](https://github.com/thor-rt/downloads/releases).

| Platform | Download |
| --- | --- |
| Linux x86-64 | AppImage for desktop or headless use |
| macOS on Apple Silicon | DMG containing THOR.app |

For installation and usage, see the [THOR documentation](https://thor-rt.org/).
